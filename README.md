# 骰子树（The Dice Tree）· 中文汉化版

基于 [HiGamezYT/The-Modding-Tree](https://github.com/HiGamezYT/The-Modding-Tree) 仓库 `dicetreenew` 分支（The Modding Tree 引擎）制作的**骰子主题放置游戏**汉化版。

## 游戏介绍

- 🎲 掷骰子赚取现金，购买升级提升掷骰收益
- ✨ 黄金骰子、彩虹骰子进阶机制
- 🎰 RNG（随机数）系统：拼运气获得更高倍率
- 📈 维度系统：用力量生产更多力量
- 🏆 成就系统，含隐藏成就

## 游玩方式

直接打开 `index.html` 即可游玩（本地或任意静态服务器均可，推荐用 GitHub Pages 部署）。

## 汉化说明

- 全部界面文本（升级、成就、标签、设置、提示、弹窗等）已翻译为简体中文
- 游戏名：骰子树；货币：现金 / 黄金骰子 / 彩虹骰子 / RNG 精华 / 力量
- 基于 `dicetreenew` 分支 v0.2「更上瘾的掷骰」版本翻译
